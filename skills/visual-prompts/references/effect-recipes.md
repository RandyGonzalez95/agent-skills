# Effect recipes

These are optional mechanisms, not a mandatory aesthetic or a guarantee of model behavior.

| Technique | Controls | Common repair |
|---|---|---|
| Slatted-light portrait | Hard key, stripe spacing/direction, face coverage, weak fill | Move a light band over the eyes or reduce coverage |
| Mirrored tunnel | Convergence behind the subject, reflection density, highlight level | Lower background brightness and reduce competing slats |
| Projected caustics | Irregular light patches, cooler background, retained skin texture | Describe illumination rather than painted color |
| Suspended prisms | Peripheral shapes, backlight, restrained spectrum glints | Reserve a clear face area and reduce prop density |
| Reflective mesh | Separate subject/background planes, soft key, restrained highlights | Soften the background rather than the face |
| Food transformation | One visible event, gravity, viscosity, trajectory, settling | Separate incompatible actions into shots and edit them together |
| Character series | Approved reference, short invariant block, scene-specific changes | Remove old scene instructions leaking into a new location |
| Alternate camera angle | Source performance and identity, bounded viewpoint change | Reduce the angle change and inspect temporal continuity |
| Field-note poster | Actual photo, reduced silhouette, texture, limited inks | Keep exact names/dates and typography in a layout tool |
| Kinetic captions | Semantic phrase groups, ordered reveals, stable anchors | Preserve qualifiers and spoken order; reduce emphasis |
| Caption depth | Footage, text, synchronized subject matte | Repair halos or move text to clear space |

Choose one dominant effect and supporting treatments only when the hierarchy remains clear. For a montage, plan final edit timing independently of the tool's generation windows. Do not infer missing source detail from a plausible generated result.
