# Monday

Discover current tools and resolve the intended workspace/board from the request or project configuration. Ask only if plausible targets remain. Read the live schema, groups, labels, items, relevant updates, and pagination; never reuse another account's IDs or defaults.

## Update

Match records by verified identity. Use supplied values and actual board defaults; optional priority is not a universal blocker. Change only requested fields. Before moving groups, check status automations. Record supplied blocking reasons without inventing owners or next actions.

On schema drift, refresh before a bounded retry. Do not create columns, labels, or other board structure outside requested scope.

## Prioritize and verify

Rank using board priority semantics, dependencies, due dates, and work in progress. Exclude completed tasks and distinguish blocked from actionable work. Explain ranking assumptions.

Read back writes and report the item link and actual state. If access fails, state what could not be verified.
